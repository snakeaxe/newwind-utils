NewwindUtils 1.0.3 — appearance editor and preview

WHAT CHANGED
- Target HUD mode is pinned as the first control and remains visible when paging.
- Screen HUD mode shows screen-panel appearance controls. Above nametag mode shows nametag controls. Controls that do not apply are hidden.
- Nametag appearance options include size, height, stacked/one-line layout, line spacing, decimal precision, preset/custom RGB colors, remaining-time colors, bold, shadow, and background opacity.
- Nametag colors and style are independent of the screen panel's palette.
- A live sample preview is visible while editing. On smaller screens it sits above the controls. Sliders update it as you drag.
- Full screen previews show screen/self panels at their configured screen positions. Return to the editor with Back to editor or Escape.
- The nametag preview includes an example player name and cosmetic title to help judge clearance. It is an illustrative fixed-distance scene; actual in-world size depends on player distance and view angle.
- Animate toggles sample countdowns and time colors. Frozen sample values are the default for easy styling.
- Previews use isolated sample data. They do not start, refresh, remove, or save actual cooldown timers. Real timer visuals are temporarily suppressed while editing/previewing; the underlying tracking continues.
- Self HUD settings have their own page and preview. The screen/self panels retain their existing shared palette, scale, text-shadow, and timer-display settings.
- Reset look restores only appearance settings for the selected view. Registered custom items, effect durations, and targeting preferences are retained.

INSTALL AND TRY
Close Minecraft, replace the old NewwindUtils JAR with newwindutils-1.0.3.jar, and launch Minecraft. Keep one NewwindUtils JAR in mods.
Press U. The first button switches between Screen HUD and Above nametag.
Change sliders or click options and watch the preview. Double-click numeric sliders for exact input. Page through appearance controls as needed; the mode selector and preview remain visible.
Use Full screen to check the screen HUD position without fighting another player. For self-panel editing choose Self HUD settings. Custom Items / Measurements and common targeting controls are below appearance settings (page through if needed).
Nametag Background Opacity runs from 0 (transparent) to 255 (opaque). Custom RGB channels use 0 to 255. Line Spacing is hidden for the one-line layout; RGB/presets are hidden while remaining-time colors are enabled.

The item-registration and measurement instructions below still apply.

REGISTER AN ITEM
1. Hold the item in your main hand and press K.
2. Choose its effect: Bind, Elytra, Food only, Gapple, All food (includes gaps), or Custom timer label.
3. Choose its source. Chest armor and leggings are detected automatically for held armor; you can change the source. Supported triggers are melee hits and right-clicking a player. Armor rules use melee hits.
4. Set Seconds, or click Recent to choose a duration recorded from the server or your stopwatch. The rule supports 0.05 to 300 seconds, in 0.05-second steps.
5. Optionally enter an exact lore line to distinguish upgraded variants that share the same item group.
6. Click Save. The rule is stored in the normal mod configuration and is active immediately, including on nearby players whose visible held/equipped item matches it.

EDIT / DISABLE / DELETE
Press U, then Custom Items / Measurements. Select a saved rule. Click its ON/OFF button or edit its fields and Save, or click Delete. Reset to Defaults preserves your custom item rules.
Rules match the captured item type and its server cooldown group. For items without a cooldown group they match item type plus the captured displayed name, so they do not apply to every item of that base type.
Register different effects for the same item as separate rules if needed. Existing built-in weapon rules remain available.

MEASURE AN EFFECT AFTER AN INCOMING HIT
1. Test with one player and one effect if possible.
2. Press L before the hit. It arms the next server-reported player damage event against you.
3. After the hit, wait until the effect actually ends, then press L again. A manual stopwatch sample is stored for this session. Pressing L a second time before a hit cancels the armed measurement.
4. Press U > Custom Items / Measurements > Last incoming hit. Choose the visible weapon, chest armor, or leggings that you believe caused the effect. These are candidates, not automatic proof of the responsible item.
5. In registration, click Recent and choose the stopwatch sample. Choose the appropriate effect/source, then Save.
An additional hit during timing can refresh an effect; that sample is marked as containing extra hits. The stopwatch measures the duration you experience and includes your reaction time. The opponent's ability recharge can be different.

AUTOMATIC LOCAL COOLDOWNS
When Newwind sends a normal Minecraft item cooldown packet, the self HUD shows Server: <affected item/group> with that packet's duration. Updates can shorten or refresh it, and a server clear removes it early. Expired timers disappear normally. The Server Cooldowns setting controls this display.
These durations also appear under Recent, labelled Server. Select a sample only when you know it corresponds to the effect you are registering. An item cooldown packet names the affected item/group; it does not identify the attacking weapon or armor. Ordinary item reuse cooldowns can appear here as well.
The client receives these standard cooldowns for your own items. It cannot query private opponent cooldowns. Other-player effect timers continue to estimate from observed matching triggers and the saved rule duration. Hidden, random, or chance-based activation cannot be proven by a hit alone. Effects implemented entirely on the server without a cooldown packet need a known duration or a manual measurement.
Recent duration samples and incoming item snapshots are session-only; saved item rules persist between launches. Disconnects/world changes clear the session. Death cancels an active stopwatch and clears active local server cooldowns.

KEYS
U: settings
K: register the item in your main hand
L: arm/cancel/finish a received-effect measurement
If another mod uses these keys, change them in Minecraft Options > Controls > Key Binds > NewwindUTILS.

BUILD SOURCE
Use the existing IDEA Java 25 setup and run .\gradlew.bat build.
